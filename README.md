# React Counter & Calculator

Basic React app using `useState`:

- **Counter** — increment, decrement, reset
- **Calculator** — add, subtract, multiply, divide for two numbers (handles empty input and divide by zero)

## Run

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Build

```bash
npm run build
```

## Structure

```
src/
  main.jsx        entry point
  App.jsx         layout
  Counter.jsx     counter component (useState)
  Calculator.jsx  calculator component (useState)
  App.css         styles
```
